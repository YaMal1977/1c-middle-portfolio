Структура модуля менеджера документа "ПланПродаж"

Основные области функционала:

1. Программный интерфейс

Регистрация механизмов проведения документа
Получение данных для формирования движений по регистрам
Управление созданием на основании и команды отчетов
Проверки при смене статуса документа
Формирование дополнительных параметров для расчетов по формулам
2. Заполнение табличной части (основной акцент)

Процедура ЗаполнитьДокумент - точка входа для фонового заполнения, которая вызывает один из трёх методов:

Метод ЗаполнитьДокументПоФормуле:

Создает таблицу периодов (дней, недель, месяцев и т.д.)
Вызывает общий механизм планирования Планирование.ЗаполнитьПоФормуле
Возвращает результат во временное хранилище
Метод ЗаполнитьПоПравилуЗаполнения (наиболее сложный):

Получает данные из различных источников по правилам заполнения через Планирование.ВыбратьДанныеПоПравилам
Обрабатывает каждую строку результата:
Округляет количество согласно настройкам точности
Пропускает пустые или нулевые значения
Три сценария распределения:
По рабочим дням: Если включено распределение и не кросс-таблица, равномерно распределяет количество по рабочим дням периода, учитывая календарь склада
По периодам (кросс-таблица): Распределяет количество пропорционально по всем периодам плана
Простое заполнение: Добавляет строки без распределения
Формирует расшифровку для каждой строки (показывает формулу расчета)
Метод ЗаполнитьДокументДляЗамещения:

Заполняет табличную часть данными из регистра накопления "ПланыПродаж"
Используется для замещения планов
3. Проведение документа

Формирование запросов для движений по регистрам "ПланыПродаж" и "ПланыОплатКлиентов"
Обработка данных из табличной части "Товары" для регистраций
4. Дополнительный функционал

Управление доступом (ограничения по партнеру, складу, подразделению)
Печать (формирование печатной формы с возможностью кросс-таблицы)
Загрузка данных из файлов
Работа с текущими делами (показатели ожидающих согласования планов)
Ключевые моменты заполнения ТЧ:

Поддержка разных периодичностей (день, неделя, месяц, квартал и др.)
Возможность кросс-таблицы (товары в строках, периоды в колонках)
Распределение по рабочим дням с учетом календарей
Округление с заданной точностью
Формирование расшифровок расчетов для пользователя
