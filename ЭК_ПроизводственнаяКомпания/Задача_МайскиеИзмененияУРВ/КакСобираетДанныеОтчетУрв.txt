Как сейчас собираются данные в отчете

1. Базовая информация 
Дата, ФИО, Линия розлива, Смена, Мастер смены: Берутся напрямую из документа «Отчет производства за смену» (вкладка «Состав рабочих»).
Руководитель берется из карточки физического лица (из его дополнительных реквизитов).

2. Отработанное время и Нормы
Отработано часов (Факт) = Берется из «Отчета производства за смену». В базе оно хранится в секундах, поэтому код делит его на 3600, чтобы получить часы.
КРВО (Коэффициент рабочего времени) = Берется из вкладки «Выпуск Итого» того же отчета производства.
Плановый КДВ  = Берется из настроек самой Линии розлива (справочник). Это цель, которую нужно выполнить.
Фактический КДВ = Берется из «Отчета производства за смену (то, что рабочие реально сделали).
Часы по графику (за вычетом больничных) = Алгоритм лезет в документ «Табель», ищет дни, где стоят буквы «Я» (Явка) или «Н» (Ночная), и суммирует длительность смены за эти дни. 
Затем смотрит, сколько дней человек был на больничном, умножает их на 12 часов и вычитает из графика.
Отработано сверх графика (Переработка)  = Считается в коде по формуле Факт часов - Часы по графику. 

3. Оклад и Ставки
Часовая ставка: Берется из регистра «Нормативы производственных операций». если человек работал на линии «Прочее», «Простой» или «Погрузчик», он берет ставку для прочих работ. Иначе — обычную ставку.
Сумма окладной части =  Считается в коде.
Для обычных линий = Часовая ставка * Отработано часов.
Для линий типа «Прочее/Простой» = Часовая ставка * Отработано часов * (КРВО / 100).

4. Нарушения и Штрафы
Сумма штрафа  = Запрос суммирует значения из вкладок «Нарушения» и «Индивидуальные нарушения» в отчете за смену.
Количество грубых нарушений  = Запрос считает, сколько раз в нарушениях стояла галочка «Грубое».
Кол-во административных нарушений = Это все нарушения минус грубые.
Кол-во нарушений технологического характера = Считается в коде. Алгоритм смотрит на процент выполнения проверок (Прокол и Электротест).
Если хотя бы один из них ниже минимально допустимого для этой линии, 
сотруднику записывается 1 технологическое нарушение.

5. Премии 
Все ставки для премий берутся из самого свежего(последнего) проведенного документа «Поощрения».
Сумма премии за работу на доп. линии = Код берет часы, которые человек отработал на дополнительной линии, и умножает их на ставку поощрения за доп. линию.
Сумма премии за соблюдение регламентов = Код считает базу: Отработанные часы * Ставка за регламент.
Если нарушений (админ + техно) = 0 — человек получает премию целиком (100%).
Если нарушение 1 — получает половину (50%).
Если нарушений 2 и больше — премия сгорает (0).
Сумма премии за работу сверх графика = Код умножает часы переработки на ставку за сверхграфик. Как и сами часы, эта сумма считается только один раз на сотрудника, чтобы СКД не задвоила выплату.
Сумма Линия (Премия за КДВ) = Если фактический КДВ больше планового, код высчитывает коэффициент превышения (с учетом шага линии) и начисляет процент от окладной части. Если достигнут «Целевой уровень», накидывается еще дополнительный бонус.
